# 📚 Glossário de Termos: Linux na Prática

Definições claras dos conceitos fundamentais encontrados nas fontes de estudo e na operação diária de sistemas Linux.

* **Bash (Bourne Again SHell):** O interpretador de comandos padrão na maioria das distribuições Linux modernas, responsável por executar os comandos digitados no terminal.
* **CLI (Command Line Interface):** Interface de Linha de Comando, ambiente onde o usuário interage com o sistema digitando comandos textuais.
* **Daemon:** Um programa executado em segundo plano (*background*) que gerencia serviços do sistema sem intervenção direta do usuário (ex: servidores web, SSH).
* **FHS (Filesystem Hierarchy Standard):** Padrão que define a estrutura e a localização dos arquivos e diretórios nos sistemas operacionais baseados em Linux/Unix.
* **Grep (Global Regular Expression Print):** Utentílio de linha de comando altamente eficiente para busca de padrões de texto utilizando expressões regulares.
* **Inod (Inode):** Estrutura de dados em sistemas de arquivos estilo Unix que armazena metadados sobre um arquivo (permissões, dono, tamanho), exceto seu nome e dados reais.
* **Pipe (`|`):** Símbolo de canalização que conecta a saída de um comando diretamente à entrada de outro.
* **Root (`/`):** O diretório raiz do sistema de arquivos Linux, ponto inicial de toda a árvore de diretórios, ou o usuário superadministrador com privilégios irrestritos.
* **Shebang:** Sequência de caracteres (`#!`) no topo de um script acompanhada do caminho do interpretador (ex: `#!/bin/bash`).
* **SSH (Secure Shell):** Protocolo de rede criptografado utilizado para realizar login remoto seguro e outras operações de rede entre computadores.
* **Stdin / Stdout / Stderr:** Respectivamente, a Entrada Padrão (teclado), a Saída Padrão (tela) e a Saída de Erro Padrão de um processo.
